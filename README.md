# 酒店降价追踪

Chrome MV3 本地插件 MVP，无依赖、无后台服务器。记录 Booking.com 当前可见房价，手动检查全部酒店的降价情况。Agoda 仅提供占位适配。

## 加载与使用

1. 在 Chrome 打开 `chrome://extensions`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择此目录。
3. 打开 `https://www.booking.com/hotel/…` 酒店页，选择入住/离店日期、房型与币种。建议使用明确的 CNY、USD 等币种标识。
4. 点击页面右下角「加入追踪」，再打开扩展 popup 查看列表、删除或「检查降价（全部）」。已有页面需刷新后才会注入按钮。
5. 检查会依次打开不激活的酒店标签页，等待可见价格后关闭。读取失败请手动打开酒店链接核对并重新加入追踪；重新加入会更新记录价。

免费每天共 3 次加入或检查；检查全部列表仅算 1 次，失败也计次，删除不计次。超限：小红书私信『珊哥爱读书』获取解锁码。在 popup「本地解锁」输入。维护者可运行 `node scripts/gen-license.mjs` 生成本项目解锁码。

运行 `npm test` 执行 Node 内置测试，无需安装依赖。

价格只是提示，不保证相同房型、税费、餐食、人数或优惠资格；¥ 和 $ 单独出现时币种不明确，无法自动比较。请自行核对取消政策与价格条款，本插件不代下单。

详细输入、存储、配额、安全边界及限制见 [FEATURE_MAP](docs/FEATURE_MAP.md)。
